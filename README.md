# 《大邮数学集》大学数学考点分类整理（总目录）

本目录基于《大邮数学集》（Release 1.5.0，`document.pdf`）整理，完整覆盖全部 **188 套大学数学课程真题**（套题 1–188，正文页码 P.1–557，不含高考套题 189–197 与附加套题 198–201），共整理 **17 份分课程文档**、**3,200+ 道真题完整题干与考点索引**。

每个细化考点（`### X.Y`）均统一包含三部分：
1. **考点索引**：全量真题定位表（套题编号、题号、书内页码、题型与考点简述）；
2. **精选例题（含参考答案）**：精选最具代表性的高频/经典真题，提供**完整题干 + 原书参考答案**；
3. **其他真题（仅题干，不含答案）**：将该考点下除精选例题外的**其余所有真题完整题干**逐条列出，不附答案，方便无剧透独立刷题自测。

**页码换算说明**：文档中标注的页码均为书内正文页码（如 `P.15`），对应 `document.pdf` 中的实际 PDF 页码满足：

$$
\text{PDF 页码} = \text{正文页码} + 14
$$

## 使用建议

1. **按高频考点突击复习**：每份文档开头均附有「高频考点分布概览表」，可先锁定占比最高的模块集中突破。
2. **先学典型例题，再刷同考点真题**：先阅读每个考点下的「精选例题（含参考答案）」掌握核心套路，再直接做紧随其后的「其他真题（仅题干，不含答案）」检验掌握程度。
3. **快速回查原卷答案**：如需核对「其他真题」的答案，可根据题目前的 `【套题 X · 题号 · P.xx】` 标签，用公式 $\text{PDF 页码} = \text{正文页码} + 14$ 直接跳转到 `document.pdf` 对应套题末尾的「答案」页核对。
