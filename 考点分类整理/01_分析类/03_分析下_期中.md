#### 精选例题（含参考答案）

1. **【套题 46 · 三.2 · P.120】**
   （15 分）求幂级数 $\sum\limits_{n=1}^\infty \frac{1}{2n-1}(x - 1)^{2n-1}$ 的收敛域及和函数。并求 $\sum\limits_{n=1}^\infty \frac{1}{(2n-1)2^n}$ 的和。

   **参考答案**：收敛域为 $(0, 2)$，和函数 $s(x) = \frac{1}{2}\ln\frac{x}{2-x}$；令 $x - 1 = \frac{1}{\sqrt{2}}$（即 $x = 1 + \frac{\sqrt{2}}{2}$），得级数的和为 $\frac{\sqrt{2}}{2}\ln(\sqrt{2} + 1)$。

2. **【套题 48 · 五 · P.126】**
   （10 分）求幂级数 $\sum\limits_{n=0}^\infty \frac{(-1)^n(2n+1)}{(2n+2)!}x^{2n}$ 的和函数。

   **参考答案**：和函数

$$
s(x) = \begin{cases}
\dfrac{x\sin x + \cos x - 1}{x^2}, & x \ne 0, \\[2ex]
\dfrac{1}{2}, & x = 0.
\end{cases}
$$

#### 精选例题（含参考答案）

1. **【套题 48 · 一.3 · P.125】**
   设

$$
f(x) = \begin{cases} x, & 0 \le x \le \dfrac{1}{2} \\ x^2, & \dfrac{1}{2} < x \le 1 \end{cases}
$$

$f(x) \sim \sum\limits_{n=1}^\infty b_n \sin n\pi x$， $b_n = 2\int_0^1 f(x)\sin n\pi x\,\mathrm{d}x$，则 $\sum\limits_{n=1}^\infty (-1)^{n-1} b_{2n-1} = \underline{\qquad}$。

   **参考答案**： $\frac{3}{8}$（提示：将 $x = \frac{1}{2}$ 代入正弦级数，左端即 $\sum_{n=1}^\infty (-1)^{n-1}b_{2n-1}$，由狄利克雷收敛定理等于 $\frac{f(1/2^-) + f(1/2^+)}{2} = \frac{1/2 + 1/4}{2} = \frac{3}{8}$）。

2. **【套题 50 · 一.9 · P.131】**
   设

$$
f(x) = \begin{cases} 1, & 0 \le x < \dfrac{1}{2} \\ x, & \dfrac{1}{2} \le x \le 1 \end{cases}
$$

$f(x) \sim \frac{a_0}{2} + \sum\limits_{n=1}^\infty a_n \cos n\pi x$， $a_n = 2\int_0^1 f(x)\cos n\pi x\,\mathrm{d}x\ (n = 0, 1, 2, \cdots)$，则 $\sum\limits_{n=1}^\infty a_n = \underline{\qquad}$。

   **参考答案**： $\frac{1}{8}$（提示： $a_0 = 2\int_0^1 f(x)\,\mathrm{d}x = \frac{7}{4}$，在 $x=0$ 处余弦级数收敛于 $f(0)=1$，故 $\sum_{n=1}^\infty a_n = 1 - \frac{a_0}{2} = \frac{1}{8}$）。

3. **【套题 52 · 一.20 · P.137】**
   设周期函数

$$
f(x) = \begin{cases} -1, & -\pi \le x \le 0 \\ 1 + x^2, & 0 < x < \pi \end{cases}
$$

则它的傅里叶级数的和函数在一个周期内的表达式为 $S(x) = \underline{\qquad}$。

   **参考答案**：

$$
S(x) = \begin{cases}
-1, & -\pi < x < 0, \\
0, & x = 0, \\
1 + x^2, & 0 < x < \pi, \\
\dfrac{\pi^2}{2}, & x = \pm\pi.
\end{cases}
$$

4. **【套题 60 · 一.7 · P.156】**
   设 $f(x)$ 是周期为 $2\pi$ 的函数，它在 $(-\pi, \pi]$ 上的表达式为 $f(x) = x + x^2$，其 Fourier 级数为 $\frac{a_0}{2} + \sum\limits_{n=1}^\infty (a_n \cos nx + b_n \sin nx)$，则 $b_3 = \underline{\qquad}$， $\frac{a_0}{2} + \sum\limits_{n=1}^\infty (a_n \cos n\pi + b_n \sin n\pi) = \underline{\qquad}$。

   **参考答案**： $\frac{2}{3}$， $\pi^2$
