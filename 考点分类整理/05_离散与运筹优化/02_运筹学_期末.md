## 一、线性规划、对偶理论与灵敏度分析

### 1.1 生产计划线性规划建模、对偶规划与灵敏度分析

#### 考点索引

| 套题 | 题号 | 页码 | 题型与考点简述 |
| :---: | :---: | :---: | :--- |
| 175 | 一、(1)–(5) | P.516 | 综合计算：线性规划建模与求解、对偶规划、资源借用（右端项变动）、新产品投产（新增变量）、工艺改进（技术系数与价值系数同步变动） |

#### 精选例题（含参考答案）

**例 1**（套题 175 第一题，P.516–517）

（40 分）已知某工厂计划生产 $X, Y, Z$ 三种产品，各产品在 $A, B, C$ 设备上加工，每件产品所需加工台时、每月设备有效台时及单位产品利润如下表所示：

| 设备 | $X$ | $Y$ | $Z$ | 每月设备有效台时 |
| :---: | :---: | :---: | :---: | :---: |
| $A$ | $5$ | $2$ | $6$ | $350$ |
| $B$ | $10$ | $6$ | $5$ | $400$ |
| $C$ | $3$ | $4$ | $6$ | $410$ |
| **单位产品利润（千元）** | $3$ | $3.5$ | $5$ | |

(1) 如何充分发挥设备能力，使生产盈利最大？
(2) 写出上述问题的对偶规划．
(3) 如果为了增加产量，可借用其他工厂的设备 $B$，每月可借用 $60$ 台时，租金为 $1.8$ 万元，问借用是否合算？
(4) 若另有两种新产品 $U, V$，其中 $U$ 需用设备 $A$ 为 $3$ 台时， $B$ 为 $5$ 台时， $C$ 为 $10$ 台时，单位产品利润 $3$ 千元；新产品 $V$ 需用设备 $A$ 为 $4$ 台时， $B$ 为 $5$ 台时， $C$ 为 $12$ 台时，单位产品盈利 $2$ 千元．如 $A, B, C$ 设备台时不增加，分别回答这两种新产品投产在经济上是否划算？
(5) 对产品工艺重新进行设计，改进结构，改进后生产每件产品 $X$，需要设备 $A$ 为 $2$ 台时，设备 $B$ 为 $13$ 台时，设备 $C$ 为 $10$ 台时，单位产品利润 $4.5$ 千元，问这对原计划有何影响？

**参考答案**：

(1) 可列线性规划问题

$$
\begin{aligned}
\max\quad & f(x) = 3x_1 + 3.5x_2 + 5x_3 \\
\text{s.t.}\quad & 5x_1 + 2x_2 + 6x_3 \le 350 \\
& 10x_1 + 6x_2 + 5x_3 \le 400 \\
& 3x_1 + 4x_2 + 6x_3 \le 410 \\
& x_1, x_2, x_3 \ge 0
\end{aligned}
$$

当产品 $X, Y, Z$ 分别生产 $0, 25, 50$ 单位时有最大生产盈利 $337.5$ 千元．（此时设备 $A, B, C$ 分别需 $350, 400, 400$ 台时．）

(2) 对偶规划为

$$
\begin{aligned}
\min\quad & g(y) = 350y_1 + 400y_2 + 410y_3 \\
\text{s.t.}\quad & 5y_1 + 10y_2 + 3y_3 \ge 3 \\
& 2y_1 + 6y_2 + 4y_3 \ge 3.5 \\
& 6y_1 + 5y_2 + 6y_3 \ge 5 \\
& y_1, y_2, y_3 \ge 0
\end{aligned}
$$

(3) 不合算（计算可得增加 $60$ 台时设备 $B$ 至多能得到 $11.68$ 千元的生产盈利，小于 $1.8$ 万元的租金）．
(4) $U, V$ 两种新产品投产都不划算．
(5) 对原计划无影响（仍然不会生产产品 $X$）．

## 二、运输问题

### 2.1 产销不平衡化平衡、最小元素法与运费差额法（Vogel 法）

#### 考点索引

| 套题 | 题号 | 页码 | 题型与考点简述 |
| :---: | :---: | :---: | :--- |
| 175 | 二、(1)–(3) | P.516 | 计算：产销不平衡运输问题化平衡，分别用最小元素法和运费差额法求初始基可行解与最优解 |

#### 精选例题（含参考答案）

**例 1**（套题 175 第二题，P.516–518）

（30 分）考虑 $3$ 个产地 $A_i,\ i = 1, 2, 3$， $4$ 个销地 $B_j,\ j = 1, \cdots, 4$ 的运输问题，产量 $a_i$，销量 $b_j$ 及单位运价 $c_{ij}$ 的数值如下表：

| | $B_1$ | $B_2$ | $B_3$ | $B_4$ | $a_i$ |
| :---: | :---: | :---: | :---: | :---: | :---: |
| $A_1$ | $6$ | $4$ | $3$ | $7$ | $9$ |
| $A_2$ | $9$ | $8$ | $10$ | $5$ | $12$ |
| $A_3$ | $4$ | $7$ | $6$ | $10$ | $14$ |
| $b_j$ | $8$ | $9$ | $10$ | $11$ | |

(1) 转化成产销平衡运输问题．
(2) 用最小元素法求出一基本可行解，并由此出发求出最优解，使总运费最小．
(3) 用运费差额法求出一基本可行解，进而求出最优解，使总运费最小．

**参考答案**：

(1) 增加虚拟产地 $A_4$，新运费表为：

| | $B_1$ | $B_2$ | $B_3$ | $B_4$ | $a_i$ |
| :---: | :---: | :---: | :---: | :---: | :---: |
| $A_1$ | $6$ | $4$ | $3$ | $7$ | $9$ |
| $A_2$ | $9$ | $8$ | $10$ | $5$ | $12$ |
| $A_3$ | $4$ | $7$ | $6$ | $10$ | $14$ |
| $A_4$ | $0$ | $0$ | $0$ | $0$ | $3$ |
| $b_j$ | $8$ | $9$ | $10$ | $11$ | $38$ |

从而转化为产销平衡运输问题．

(2) 最小元素法得到初始基可行解：

| | $B_1$ | $B_2$ | $B_3$ | $B_4$ | $a_i$ |
| :---: | :---: | :---: | :---: | :---: | :---: |
| $A_1$ | | | $9$ | | $9$ |
| $A_2$ | | $1$ | | $11$ | $12$ |
| $A_3$ | $5$ | $8$ | $1$ | | $14$ |
| $A_4$ | $3$ | | | | $3$ |
| $b_j$ | $8$ | $9$ | $10$ | $11$ | |

调整得到最优解：

| | $B_1$ | $B_2$ | $B_3$ | $B_4$ | $a_i$ |
| :---: | :---: | :---: | :---: | :---: | :---: |
| $A_1$ | | | $9$ | | $9$ |
| $A_2$ | | $1$ | | $11$ | $12$ |
| $A_3$ | $8$ | $5$ | $1$ | | $14$ |
| $A_4$ | | $3$ | | | $3$ |
| $b_j$ | $8$ | $9$ | $10$ | $11$ | |

去掉虚拟产地，最小总运费为 $163$．

(3) 运费差额法得到初始基可行解：

| | $B_1$ | $B_2$ | $B_3$ | $B_4$ | $a_i$ |
| :---: | :---: | :---: | :---: | :---: | :---: |
| $A_1$ | | | $9$ | | $0$ |
| $A_2$ | | $4$ | | $8$ | $0$ |
| $A_3$ | $8$ | $5$ | $1$ | | $0$ |
| $A_4$ | | | | $3$ | $0$ |
| $b_j$ | $0$ | $0$ | $0$ | $0$ | |

调整得到的最优解与最小元素法相同．
